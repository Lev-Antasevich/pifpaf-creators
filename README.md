# PifPaf Creators

Кабинет для блогеров PifPaf: каждый заводит свой аккаунт, добавляет Instagram Reels по ссылке и видит обложку, дату и просмотры в ленте и аналитике.

Цифры подтягиваются через [Apify](https://apify.com) (бесплатного тарифа хватает).

## Что умеет

- Регистрация и вход — у каждого свой кабинет и свои рилсы
- Добавление рилса по ссылке из Instagram
- Автоподгрузка обложки, даты публикации, просмотров, лайков и комментариев
- Обновление статистики по одному ролику или по всем сразу
- Лента карточками и таблица со всеми метриками
- Обзор и аналитика: суммарные просмотры, средний охват, вовлеченность, график
- Профиль: имя, Instagram, выход из аккаунта

## Как запустить

Нужен [Node.js](https://nodejs.org/) 18 или новее.

```bash
git clone https://github.com/Lev-Antasevich/pifpaf-creators
cd pifpaf-creators
npm install
cp .env.example .env
npm start
```

Сайт откроется на [http://localhost:3847](http://localhost:3847).

На главной — экран входа. Можно зарегистрироваться или открыть демо:

- email: `demo@pifpafai.com`
- пароль: `pifpaf`

## Apify (по желанию)

Чтобы с ссылки реально подтягивались просмотры и обложка:

1. Создай бесплатный аккаунт на [Apify](https://console.apify.com/account/integrations)
2. Скопируй API token
3. Вставь его в `.env`:

```
APIFY_TOKEN=apify_api_...
APIFY_ACTOR=apify/instagram-scraper
```

4. Перезапусти `npm start`

Без токена кабинет тоже работает: рилсы сохраняются по ссылке, цифры появятся после подключения Apify.
